PROJECT TITLE: Aerogen Air Services
PROJECT DESCRIPTION:
Aerogen is an aircraft rental agency where it allows customers to use the aircraft for different purposes. It also helps customers to find the best aircraft for their needs.

FEATURES: The app will include a booking option for customers.
The aircrafts will be displayed in a cardview.
Each aircraft has its own specification so that the customer
will know the difference of each capacity that the plane offers.
The app also has an API which is OpenWeather so that the customer
will be aware of the destination's weather.

TARGET USERS:
Airlines ( globalwide)
Private individuals
Business professionals
Administrators in the Aerogen company

Objectives:

1.To enable customers give more options on choosing the plane they prefer

2. To provide user friendly experience to our values customers

3. To provide real time information about the aircraft and weather of the destination.
