PROJECT TITLE: Aerogen Air Services
PROJECT DESCRIPTION: 
Aerogen is an aircraft rental agency where it allows customers to use the aircraft for different purposes. It also helps customers to find the best aircraft for their needs. 

FEATURES: The app will include a login page for both admin and customers. It will also feature search and filter options where it will filter price, aircraft manufacturer, range of the plane. It will also allow the customer to choose the plane they would like to book.  For the admin side, the admin has the option to delete, update, create the planes currently available. It also has the weather forecast to check if the location they are departing/arriving location’s weather is stable or not. The customers have the option to check their booking history from their account. 


TARGET USERS: 
Airlines ( globalwide)
Private individuals
Business professionals
Administrators in the Aerogen company

Objectives:

To enable customers to search for aircraft by model, manufacturer, price, and range using a search bar and filter options.
To Provide admins with the ability to add new aircraft to the system, including details like model, manufacturer, price, range, and availability.
To allow customers to view their booking history and booking confirmations within the app, and provide admins with the ability to view and manage customer bookings
